# Loom v0.4 路线图与发布计划

> 状态：讨论稿<br>
> 关联：[产品定位](loom-product-positioning.md)、[核心 Agent PRD](v0.4-core-agent-prd.md)、[工作流 PRD](v0.4-workflow-automation-prd.md)

## 1. 路线图目标

v0.4 的主题是“让本地 Agent 能够持续、可控地完成工作”。本版本不以扩展模式数量为成功标准，而以核心任务闭环、可解释的上下文沉淀和可信工作流为准。

## 2. 产品状态定义

| 状态 | 定义 | 对用户的表达 |
| --- | --- | --- |
| Stable | 有文档、兼容承诺、自动化覆盖与迁移策略 | 可用于日常关键任务。 |
| Preview | 可用但接口、数据格式或交互可能调整 | 可试用，请反馈。 |
| Experimental | 用于验证方向，可能删除或重做 | 不用于关键生产流程。 |
| Planned | 已决定方向，尚未可用 | 不出现在默认推荐流程。 |

`evolve` 当前为 Planned；浏览器扩展、任务/公司模式等应至少标为 Experimental，除非完成相应发布门槛。

## 3. 阶段与成果

| 阶段 | 结果 | 主要依赖 | 发布判定 |
| --- | --- | --- | --- |
| 0：产品基线 | README、PRD、术语、能力状态一致 | 文档与命令审计 | 用户能区分可用/实验/未实现。 |
| 1：核心 Agent 闭环 | CLI 可启动、观察、取消和继续会话 | 模型、工具、checkpoint | P0 核心 Agent 验收通过。 |
| 2：上下文可控 | 记忆/技能可管理、可解释、可审阅 | memory、skill、curator | 用户可知道并控制影响行为的上下文。 |
| 3：工作流可信 | 实例化、后台执行、摘要、诊断、取消/恢复 | tool-workflow、Luft 合约 | 终态完整、输出受控、诊断可用。 |
| 4：入口一致 | ACP 达到与 CLI 一致的核心语义；Bot 明确边界 | ACP 协议、共享运行选项 | 共享契约测试通过。 |
| 5：v0.4 发布 | 发布说明、迁移说明、已知限制与反馈通道 | 前述所有阶段 | 发布清单全部满足。 |

阶段可并行开发，但下一阶段不能把前一阶段未解决的 P0 问题隐藏在新入口中。

## 4. 优先级与取舍

### P0：必须随 v0.4 交付

- 任务的工作目录、模型、会话和终态可见。
- CLI/ACP 的会话与取消语义一致。
- 文件、Shell、MCP、浏览器等高影响操作有明确权限与数据规则。
- 工作流具备受控摘要、分页诊断和终态完整性。
- 记忆与技能能被查看、编辑、删除，且加载可解释。

### P1：v0.4 中完成或明确降级

- 工作流恢复、工作目录锁和大输出引用。
- 会话复盘的审阅式更新。
- CLI/ACP 的统一帮助、错误信息和项目状态视图。

### P2：验证后再扩大

- Telegram Bot 的持续上下文体验。
- 浏览器扩展的安装与权限体验。
- 任务/公司模式、自动 Agent 编排与工作流模板市场。
- 云同步、团队共享、托管运行。

## 5. 每阶段统一完成定义

一个能力只有同时满足以下条件，才能从 Preview/Experimental 升级：

1. 对应 PRD 的 P0 验收标准有自动化或可重复端到端证据。
2. 用户文档、命令帮助、错误信息和数据路径一致。
3. 明确失败、取消、删除、迁移和回滚行为。
4. 不泄露密钥；不因可选的追踪、复盘或日志失败而阻断主任务。
5. 已知限制被写入发布说明，并有反馈/问题归档渠道。

## 6. 发布清单

- [ ] `README.md` 以产品任务流而非 crate 列表作为首屏叙事。
- [ ] 所有默认入口说明实际可用的命令；未实现命令不被推荐。
- [ ] `.loom/` 目录结构、保留和清理策略已发布。
- [ ] CLI、ACP、工作流关键路径通过集成测试。
- [ ] 权限策略和隐私说明已审阅。
- [ ] 从旧 `.luft/` 工作流产物的兼容时限与迁移行为已发布。
- [ ] 发行说明列出新增能力、破坏性变化、已知限制与升级步骤。

## 7. 风险与触发器

| 风险 | 触发器 | 决策 |
| --- | --- | --- |
| 多入口分叉 | CLI/ACP 行为不一致 | 暂停新增入口功能，优先补共享契约。 |
| 上下文不可信 | 用户无法解释记忆/技能影响 | 关闭自动应用，转为建议模式。 |
| 工作流不可诊断 | 缺失终态或大输出压垮上下文 | 不升 Stable，优先可靠性与摘要。 |
| 高风险工具误用 | 无法解释权限或越界访问 | 默认收紧策略并补确认流程。 |
