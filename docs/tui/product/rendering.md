# 产品文档：渲染层

## 概述

渲染层是 Loom TUI 系统中的第 3 层，负责统一的 UI 组件渲染和视觉呈现管理。它定义了标准化的渲染接口，提供丰富的布局组件和专用渲染器，通过灵活的渲染管线支持终端用户界面的高质量显示。

渲染层抽象了底层终端渲染细节，为上层应用提供声明式的 UI 组件构建方式，同时保持足够的灵活性来支持复杂的交互需求。

## 用户价值

**一致性的视觉体验**
- 统一的渲染接口确保所有组件遵循相同的视觉规范
- 标准化的布局模式提供可预测的界面结构

**高效的终端利用**
- 动态高度计算自动适配不同终端窗口尺寸
- 智能布局组件最大化利用有限的终端空间

**丰富的信息呈现**
- 差异渲染突出显示文件变更内容
- 流式渲染提供实时的 AI 响应反馈
- 状态指示器清晰传达系统运行状态

**流畅的交互体验**
- 精确的光标定位支持键盘导航
- 动画进度指示器提供视觉反馈
- 响应式更新支持实时数据变化

## 核心组件

### 渲染抽象层

**Renderable Trait**
所有 UI 组件必须实现的核心接口：
- `render(self, area, buf)` - 将组件渲染到指定区域的缓冲区
- `desired_height(width) -> u16` - 根据宽度计算所需渲染高度
- `cursor_pos(area) -> Option<(u16, u16)>` - 获取光标位置
- `cursor_style(area) -> SetCursorStyle` - 设置光标样式

### 布局组件

**ColumnRenderable**
- 垂直堆叠子组件
- 自动分配子组件高度
- 适用于消息列表、日志输出等垂直排列内容

**RowRenderable**
- 水平排列子组件
- 按比例分配宽度空间
- 适用于工具栏、状态栏等水平布局

**FlexRenderable**
- 弹性布局算法
- 根据组件权重智能分配空间
- 支持复杂混合布局场景

**InsetRenderable**
- 内边距包装组件
- 为子组件添加统一边距
- 确保组件间距和边界清晰

### 专用渲染器

**历史消息渲染**
- 渲染已完成的对话单元格
- 支持格式化文本、代码块等复杂内容
- 复用现有 `history_cell/` 模块

**流式内容渲染**
- 实时渲染正在输出的内容
- 逐字符或逐行的渐进式显示
- 复用 `display/streaming_markdown.rs` 的流式处理

**差异内容渲染**
- 文件变更内容的高亮显示
- 绿色/红色标示新增/删除内容
- 精确的行级差异显示

**动画渲染器**
- Spinner 动画进度指示
- 支持多种动画帧模式
- 复用 `display/spinner.rs` 的帧动画引擎

**状态指示渲染**
- AI 状态行显示
- 思考中、执行中等状态可视化
- 清晰的状态图标和文本描述

### 渲染管线

**主渲染循环**
```
App::render()
  → 计算所需高度（desired_height 递归求和）
  → Tui::draw(height, |frame| {
      for cell in history { cell.render(area, buf); }
      if let Some(active) = active_cell { active.render(area, buf); }
      pane_stack.render(area, buf);
      frame.set_cursor_position(pane_stack.cursor_pos(area));
    })
```

**高度计算阶段**
- 递归计算所有组件所需高度
- 根据终端窗口宽度动态调整布局
- 支持内容自适应和滚动处理

**绘制阶段**
- 按照布局层次逐层渲染组件
- 应用主题样式和高亮效果
- 处理复杂内容的分页和截断

**光标管理**
- 精确的光标位置计算
- 支持组件内的光标定位
- 统一的光标样式管理

## 与其他层的关系

**与终端层的关系**
- 依赖终端层提供的底层渲染能力（ratatui）
- 将抽象的渲染指令转换为终端可执行的绘制操作
- 响应终端层的窗口大小变化事件

**与交互层的关系**
- 接收交互层的渲染请求和状态更新
- 为交互层提供组件边界和光标位置信息
- 协同实现实时响应的交互体验

**与应用层的关系**
- 接收应用层的渲染指令和数据更新
- 支持应用层的主题配置和样式定制
- 提供高层接口简化应用层的渲染逻辑

**数据流向**
终端层 → 渲染层 → 应用层：事件向上传递
应用层 → 渲染层 → 终端层：渲染指令向下执行

## 关键设计决策

**统一接口抽象**
- 采用 Renderable trait 统一所有组件的渲染行为
- 降低组件间的耦合度，提高代码可维护性
- 便于扩展新的 UI 组件类型

**渐进式渲染**
- 支持流式内容的逐步渲染和更新
- 优化大量内容的渲染性能
- 提供更流畅的用户体验

**智能布局管理**
- 动态高度计算适应不同终端尺寸
- 灵活的布局算法支持复杂界面设计
- 内边距和间距的统一管理

**视觉反馈强化**
- 差异渲染突出显示重要内容变化
- 动画和状态指示提供系统状态反馈
- 清晰的光标定位支持键盘交互

## 使用场景

**对话界面**
- 历史消息的垂直堆叠显示
- AI 流式响应的实时渲染

- 日志级别的颜色区分
