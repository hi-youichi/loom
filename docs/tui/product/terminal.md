# 产品文档：终端层

## 概述

终端层是 Loom TUI 系统的第二层，负责终端硬件抽象、事件捕获和内联视图管理。它是所有上层组件的基础，为整个 TUI 系统提供终端交互的核心能力。

**核心价值**：在保持终端原生体验的同时，提供高效的交互界面和事件处理机制。

## 用户价值

| 用户价值 | 具体表现 |
|----------|----------|
| **无感嵌入** | TUI 界面嵌入终端正常滚动历史，不占用全屏，不破坏终端工作流 |
| **响应迅速** | 原生事件捕获和高效帧调度，确保流畅的用户交互体验 |
| **状态保持** | 支持暂停/恢复，终端历史完整保留，可随时切换到其他工作 |
| **系统兼容** | 兼容终端原生操作（复制粘贴、滚动、resize），支持全屏模式切换 |

## 核心组件

### 终端初始化
- **功能**：设置终端为 raw mode、启用 bracketed paste、配置 panic hook
- **用户价值**：确保终端行为一致，避免意外退出，提供稳定的使用环境

### 内联视图
- **功能**：管理 viewport 位置和渲染区域，在终端滚动区域中划出 TUI 渲染空间
- **用户价值**：保持终端历史的连续性，不独占终端，与其他终端工具共存

### 事件系统
- **功能**：事件捕获、分发、暂停/恢复，支持键盘、粘贴、窗口调整等事件
- **用户价值**：响应灵敏的交互体验，支持丰富的输入方式

### 历史行插入
- **功能**：将聊天历史写入终端滚动区域，每次渲染时先 flush 待处理的历史行
- **用户价值**：完整的对话历史可查看，保留终端上下文，支持回溯操作

### Job Control
- **功能**：支持 `^Z` 暂停/恢复 TUI 会话
- **用户价值**：可随时切换到其他命令工作，灵活的多任务处理

### Alt Screen
- **功能**：全屏模式切换，用于文件编辑器等特殊场景
- **用户价值**：在需要更大显示区域时提供全屏体验

### 光标管理
- **功能**：控制光标位置和样式
- **用户价值**：精确的输入位置指示，提升交互精度

### 帧调度
- **功能**：控制绘制频率，避免过度绘制
- **用户价值**：优化性能，减少终端闪烁，提供流畅的视觉体验

## 与其他层的关系

| 层级 | 关系 |
|------|------|
| **基础设施层** | 终端层基于 crossterm、ratatui 等基础设施，直接调用终端 API |
| **渲染层** | 终端层提供渲染区域（viewport）和事件触发，渲染层负责具体内容绘制 |
| **交互层** | 终端层捕获用户输入事件，交互层处理具体交互逻辑 |
| **应用层** | 终端层提供基础能力和事件流，应用层协调整体业务逻辑 |

**协作方式**：终端层作为底层支撑，向上提供稳定的事件流和渲染容器，其他层在此基础上构建具体功能。

## 关键设计决策

### 内联视图而非 Alternate Screen
- **决策**：在终端正常滚动区域中划出 viewport，不使用 alternate screen
- **理由**：保留终端历史，支持多进程共存，避免工作流中断
- **用户价值**：更自然的终端使用体验

### 统一事件流架构
- **决策**：crossterm → TuiEventStream → TuiEvent → EventBroker → App 主循环
- **理由**：分层处理，支持 pause/resume，多消费者并发
- **用户价值**：稳定的事件处理，支持复杂交互场景

### 历史行优先插入策略
- **决策**：每次 draw() 时先 flush 历史行到 viewport 上方
- **理由**：确保对话历史的连续性和完整性
- **用户价值**：完整的对话记录，不会丢失历史信息

## 使用场景

| 场景 | 用户行为 | 系统响应 |
|------|----------|----------|
| **日常对话** | 用户在终端输入命令启动 TUI | 终端层初始化 raw mode，在当前历史位置创建内联视图 |
| **多任务切换** | 用户按 `^Z` 暂停 TUI | 终端层触发 Job Control，恢复终端正常模式 |
| **工作恢复** | 用户输入 `fg` 恢复 TUI | 终端层重新激活事件流，恢复内联视图状态 |
| **窗口调整** | 用户调整终端窗口大小 | 终端层捕获 resize 事件，重新计算 viewport 位置 |
| **全屏编辑** | 用户打开文件编辑器 | 终端层切换到 alternate screen，提供全屏体验 |
| **历史回溯** | 用户滚动终端查看历史 | 终端层保持历史行完整性，用户可查看完整对话记录 |
