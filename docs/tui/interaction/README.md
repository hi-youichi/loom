# Loom TUI 交互文档

## 文档结构

```
docs/tui/interaction/
├── README.md              # 本文档 - 交互文档索引
├── architecture.md        # 交互架构（新写） - 事件处理、视图栈、状态机、按键映射
├── reference-codex.md     # Codex CLI 参考（已迁移） - 基于代码库的交互分析
└── ...

product/interaction.md     # 产品文档 - 用户视角的交互层介绍
```

## 文档导航

| 文档 | 视角 | 内容 | 适合读者 |
|------|------|------|----------|
| `product/interaction.md` | **用户/产品** | 概述、用户价值、核心组件、设计决策、使用场景 | 产品经理、用户 |
| `architecture.md` | **架构/工程** | 事件处理模型、视图栈、状态机、按键映射、组件协作 | 开发者、架构师 |
| `reference-codex.md` | **参考/逆向** | Codex CLI 的交互设计分析、按键映射、布局细节 | 开发者（实现参考） |

## 三个文档的关系

```
产品文档 (product/interaction.md)
  └── 定义"要做什么" (What)
        │
        ▼
架构文档 (architecture.md)
  └── 定义"怎么设计" (How)
        │
        ▼
参考文档 (reference-codex.md)
  └── 提供"别人怎么做" (Reference)
```
